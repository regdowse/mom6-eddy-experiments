# MOM6 eddy experiments

Idealised MOM6 experiments investigating how planetary and topographic potential vorticity gradients influence the three-dimensional structure and tilt of ocean eddies.

This repository is at the planning stage. The initial work will develop a traceable control and a small planetary-beta pilot using ACCESS-NRI experiment tools, subject to compatibility checks.

The existing sandbox experiments remain as legacy references at `/g/data/fu5/users/rd7475/github/phd/idealised_modelling/mom6_sandbox/`. The current starting point is `mom6-eddy-exp1-layer-vortdiag/`.

The `context/` directory contains working notes and a proposed pilot specification. These notes are pending review for publication and may reference unpublished or private research. No experiments have been created or run in this repository.
